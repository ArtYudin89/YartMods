# TowBeam — буксировочный луч для Space Rangers HD: A War Apart

Любой исправный захват получает буксировочный луч: предмет из космоса можно тащить за кораблём,
не поднимая на борт. При посадке на планету или станцию груз сразу уходит на склад этого места.

## Как играть

| Действие | Как |
|---|---|
| Взять предмет на буксир | клавиша **0** или кнопка на левом краю панели оружия → навести луч на предмет |
| Отцепить один груз | в режиме наведения щёлкнуть по грузу на тросе |
| Отцепить всё | **Shift+0** или правая кнопка по кнопке луча |
| Настройки | бортовые настройки капитанского мостика (мод ExpPilotBridge); без мостика — значения по умолчанию |

Что происходит, пока груз на тросе:
- корабль тяжелеет на массу груза — так же, как если бы груз лежал в трюме (место в трюме не занимает);
- оружие молчит (или каждый груз закрывает оружейный слот — настройка);
- до 5 грузов цепочкой; общий предел массы — мощность захвата × 10 (настройка: ×5, 10, 15, 20, 30, без предела);
- трос рвётся, если захват снят или сломан, при ЭМ-помехах, от сильного удара (настройка, по умолчанию
  20 % корпуса за ход) и при прыжке или в чёрной дыре (настройка: рвётся / груз летит с вами / прыгать нельзя);
- NPC груз на тросе не трогают (настройка: или как обычный предмет);
- груз, путь которого проходит у самой звезды, сгорает — перед этим мигает предупреждение.

Мод можно подключить в начатой партии, но **убрать из неё нельзя**: сейв, сохранённый с модом, без него
не загрузится (в журнале игры — «Failed to load script: Script.TowBeam»). Пункт «выключить» в бортовых
настройках — пауза: отцепляет грузы и снимает всё, что мод добавил кораблю, но скрипт остаётся в сейве.

Зависимость — `UtilityFunctionsPack` (из него `GetShipPath`, `GetParFromString` и др.).

## Устройство

- `src/DATA/Script/TowBeam.src/` — скрипт (`.rsm`, собирается `rsmc`): вся логика в `code.rsm`.
- `src/CFG/Rus|Eng/Lang.txt` — тексты, числа `TowBeam.Cfg.*` (их можно менять без пересборки скрипта)
  и служебная метка `TowBeam_Info`, чей код получает шаги хода, наведение и открытие форм.
- `src/CFG/Main.txt` — регистрация скрипта, проверка после загрузки сейва, клавиши, кнопка.
- `src/DATA/Interface/*.png` — кнопка (три состояния), `src/CFG/CacheData.txt` — пути к ней.

Решения движка, на которых всё держится (подробно — в комментариях `code.rsm`):
груз — сам предмет, который каждый ход снимается из системы и пускается лететь за корму
(`GetItemFromStar` + `DropItemInSystem` с конечной точкой); замедление — бонус массы корабля;
оружие — эффект блокировки орудий или бонус числа оружейных слотов; защита от NPC — именованные
скриптовые объекты `Cargo0..Cargo4`; луч — `ShowEffect` на шагах хода.

Ловушки языка, на которые уже наступили: `'<Имя>'` в строке компилятор делает подстановкой
переменной (метки для `Format` — `#Имя#`); `float(...)` — не преобразование; тип выражения задаёт
левый операнд (`0 - cos(x)` считается в целых — пишем `0.0 - …`).

## Сборка и проверка

```
python -m srmod build                 # src/ -> build/  (PYTHONPATH=..\sr-modkit)
python tools/make_debug.py            # build/ -> build-debug/ с Debug=1 (клавиша 9: ящик на буксир и полёт вперёд)
python ..\sr-lab\sr.py test local build --as Artem\TowBeam --deps steam --turns 5 --where host
python ..\sr-lab\sr.py script run tests\lab-tow.json      # захват, полёт, цепочка, отцепка, обрывы, склад, прыжок
python ..\sr-lab\sr.py script run tests\lab-modes.json    # режимы настроек, обрывы, загрузка сейва
python ..\sr-lab\sr.py script run tests\lab-dialogs.json  # пункты бортовых настроек
python ..\sr-lab\sr.py script run tests\lab-debug.json    # отладочная клавиша 9 (build-debug)
```

Установка в игру: `python -m srmod deploy --game "<папка игры>"` — ссылка `Mods\Artem\TowBeam` → `build/`;
затем включить мод в списке модов игры.

## Проверка в окне игры

Лаборатория не видит интерфейс: место кнопки, вид луча, строки мостика, экраны склада и корабля
смотрятся в окне (вариант движка `srlab`, окно 1280x720, ввод и снимки из скрипта; во время прогона
компьютером не пользоваться, прогоны — по одному).

```
python ..\sr-lab\sr.py script run tests\bridge-world.json   # мир с ExpPilotBridge после взлёта -> tests\worlds\
python tools\make_variant.py beam_D2 BeamEffect=Weapon.10 BeamPalette=2   # вариант настроек -> .window\variants\
set VS_MODS=Tweaks/UtilityFunctionsPack,Tweaks/TechnicalIssuesFixer,Expansion/ExpBK,Expansion/ExpPilotBridge,Artem/TowBeam
python tools\window_session.py tests\worlds\bridge_world.sav vs-bridge шаги.json   # снимки -> .window\shots\
```

Формат шагов — в начале `tools/window_session.py`. Найдено в окне 10.10.2026: кнопку держать внутри
полосы оружия `PS_Up` (за краем панели игра не рисует); в строках мостика метка `#V#`, а не `<0>`
(литерал `'<0>'` rsmc собирает в `Format('<0>',"<0>",0)`); шрифты игры без длинного тире и знака «×».
