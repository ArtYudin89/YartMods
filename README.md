# YartMods — моды Yart для Space Rangers HD: A War Apart

Мои моды для «Космических рейнджеров HD: Революция». Каждый мод — отдельная папка с исходниками;
готовая сборка всех модов — в [последнем релизе](../../releases/latest).

| Мод | Что делает | Папка в игре | Нужен | Сборки |
|---|---|---|---|---|
| [TowBeam](TowBeam/README.md) — буксировочный луч | захват тащит предмет из космоса за кораблём, не поднимая на борт; при посадке груз уходит на склад | `Mods\Artem\TowBeam` | UtilityFunctionsPack | Steam-версия, Universe, Redux; **не** Original |

В сборке Original старые движок и UtilityFunctionsPack: в них нет функций, на которых держится луч.

## Установка

**Через лаунчер модов** [sr-mods-launcher](https://github.com/ArtYudin89/sr-mods-launcher): моды есть
в его каталоге, новые версии попадают туда после выпуска здесь (каталог обновляется раз в сутки).

**Вручную:**
1. Скачать [YartMods.zip](https://github.com/ArtYudin89/YartMods/releases/latest/download/YartMods.zip) —
   ссылка всегда ведёт на последнюю сборку.
2. Распаковать в папку игры (где лежит `Rangers.exe`): моды лягут в `Mods\Artem\…`.
3. Включить нужный мод в меню модов игры вместе с его зависимостями.

> Буксировочный луч можно подключить в начатой партии, но **убрать из неё нельзя**: сейв,
> сохранённый с модом, без него не загрузится.

## Разработка

- Мод — проект [sr-modkit](https://github.com/ArtYudin89/sr-modkit) (`srmod.json`): исходники в `src/`,
  сборка `python -m srmod build` → `build/`. Подробности — в README мода.
- `python tools/release.py` собирает все моды и упаковывает `dist/YartMods.zip` (внутри только `Mods/…`);
  с `--publish vX.Y.Z --notes <файл>` выкладывает архив релизом. Имя архива во всех релизах одно —
  поэтому ссылка на последний релиз постоянная.
- Сценарии проверки модов (`<мод>/tests/`) гоняются в лаборатории sr-lab, она не публикуется.
